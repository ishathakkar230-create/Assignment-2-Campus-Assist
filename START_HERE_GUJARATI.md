# Pela aa karo

1. ZIP ne nava short-path folder ma Extract All karo. A1 ane A2 alag folders ma rakhvana.
2. `SETUP_WINDOWS.cmd` double-click karo. Packages install thava do.
3. Puchhe tyare 12+ characters na local passwords set ane repeat karo. Screen par typing nahi dekhay, normal chhe.
4. VS Code ma `.env` kholo. Placeholder ni jagyae tamari GROQ key paste kari save karo. Key chat, GitHub ke video ma na batavsho.
5. `START_WINDOWS.cmd` kholo. Terminal no Local URL browser ma kholo.
6. Student S001 select kari tamaro local password nakho.
7. VIDEO_SCRIPT.md na scenarios ek-ek kari chalavo. Dar ek run no trace download karo.
8. `EVALUATE_WINDOWS.cmd` thi real questions run karo. JSON na answers review kari CSV na pass/tool columns ma 1 ke 0 bharo.
9. Banne na CSV par compare_results.py chalavo. A2 ma reviewer approval/rejection pan demonstrate karo.
10. Public GitHub ane tamaro recorded explanatory video ni links instructor na form ma submit karo.

Code ane offline tests taiyar chhe. Aa packaged version no real API evaluation, tamaro video ane public GitHub submission tamara laptop/account par karvana chhe. Live results ni jagyae offline test counts na lakho.

A2 ma S001, S002 ane reviewer tran login chhe. Student programme-change request kare; sign out kari reviewer thi approve/reject karo. Pachhi student thi login kari official programme check karo. Reject karta koi change na thavo joie.
